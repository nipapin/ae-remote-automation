# Rainbow template

1. In After Effects: **File → Save As**
2. Save as:

```
templates/rainbow/template.aep
```

Composition must be named **Main**.

Expected layers:
- `top_text` (text)
- `main_text` (text)
- `bottom_text` (text)
- `main_text_bg` (shape — white box)
- `bg` (shape — background)

After saving, refresh http://localhost:3000 and choose **Rainbow Text (Main)**.
